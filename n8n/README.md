# 오후 실습 — 노코드로 같은 일 하기

오전에 코드로 만든 "요약 보고"를, 오후에는 **노코드로** 만듭니다.
전원이 **똑같은 레일**을 한 번 끝까지 돌린 다음, 각자 자기 업무로 갈아 끼웁니다.

## 레일

```
매일 아침 8시  →  뉴스 가져오기  →  한국어로 요약  →  나에게 메일
 (스케줄)        (HTTP · 공개 API)    (LLM 1회)        (Gmail)
```

**API 키가 하나도 필요 없습니다.** 계정은 구글 하나뿐입니다.

| 단계 | 어떻게 인증하나 |
|---|---|
| 뉴스 가져오기 | 공개 API라 인증 없음 |
| 한국어로 요약 | credential 칸에서 **`Use Gateway credits`** 선택 — n8n이 대신 호출합니다 |
| 나에게 메일 | **`Sign in with Google`** 한 번. Google Cloud Console 설정은 필요 없습니다 |

## 가져오기

N8N 화면 오른쪽 위 **⋯ → Import from File** 에서 [`rail-skeleton.json`](rail-skeleton.json)
을 고릅니다.

> [!TIP]
> **망가뜨려도 괜찮습니다.** 다시 import하면 처음 상태로 돌아옵니다.
> 1회차의 `git restore .` 와 같은 역할입니다.

## 반드시 지킬 것 — LLM은 한 번만

> [!CAUTION]
> **AI Agent 노드에 도구를 붙여 루프를 돌리지 마세요.**
> 실행 한 건에 모델 호출이 열 번 넘게 나가고, 그게 그대로 크레딧입니다.
> **체험판은 크레딧을 다 쓰면 충전할 수 없습니다.** 수업 중에 멈춥니다.
>
> 레일이 끝까지 돌아간 다음, 맨 마지막에 한 번만 구경합니다.

같은 이유로 **계정을 친구와 공유하지 마세요.** 잔액은 인스턴스 단위로 공유됩니다.

## 테스트 — 일부러 깨 봅니다

돌아가는 걸 만든 다음이 진짜 시작입니다.

1. 왼쪽 메뉴 **Executions** 에서 방금 실행을 엽니다
2. 노드를 하나씩 눌러 **들어온 데이터와 나간 데이터**를 봅니다
3. 일부러 깨 봅니다 — URL의 글자 하나를 바꾸거나, 요약 지시문을 비워 봅니다
4. 어디서 멈추는지, 메시지가 뭐라고 하는지 읽습니다

**에이전트 개발의 대부분은 이 화면을 읽는 일입니다.**

## 내 업무로 갈아 끼우기

오전에 쓴 [워크시트](../worksheet/워크시트.md)를 꺼냅니다. 레일에서 **바꾸는 건 양 끝**입니다.

| 워크시트 칸 | 레일에서 |
|---|---|
| **트리거** | `매일 아침 8시` 를 바꾼다 (시간 / 웹훅 / 메일 수신) |
| **처리** | `뉴스 가져오기` 와 `한국어로 요약` 을 바꾼다 |
| **액션** | `나에게 메일` 을 바꾼다 (메일 / 시트 기록 / 메시지) |

노코드로 안 되는 게 나오면 — **그때가 오전에 배운 걸 쓸 때입니다.**
Codex에게 Code 노드에 넣을 자바스크립트를 쓰게 하세요. 거기가 코드와 노코드가
만나는 지점이고, 오늘 마지막에 이야기할 주제입니다.
